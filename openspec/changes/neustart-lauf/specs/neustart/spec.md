## ADDED Requirements

### Requirement: Zählerordner

Das Repository SHALL unter `src/neustart/<name>/` für alfa, bravo, charlie, delta und echo je die Dateien `1.txt` bis `5.txt` enthalten, jede mit ihrer Nummer als einziger Zeile.

#### Scenario: Dateien vorhanden

- **WHEN** das Repository ausgecheckt ist
- **THEN** enthält jeder Ordner fünf Dateien mit je ihrer Nummer
